## Permissions

This mod is **FREE** and must always stay free; it is not for sale.

Because v1.3 ships KAVT compatibility definitions under the KAVT author's published permission terms, **Donation Points must remain disabled for this release**. No KAVT tattoo textures are bundled.

## KAVT permission condition

The KAVT Nexus page states: "You are allowed to use the assets in this file without permission as long as you credit me." The published permission terms also prohibit earning Donation Points when those assets are used. This release therefore retains the KAVT credit, excludes KAVT tattoo textures, and requires Donation Points to remain disabled.

Primary permission source: https://www.nexusmods.com/baldursgate3/mods/16325
