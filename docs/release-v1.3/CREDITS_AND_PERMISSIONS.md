## KAVT interoperability

The tattoo correction contains compatibility material definitions derived from the behavior required to interoperate with **KAVT - Kazstra's Virtual Tav x Tattoo Makeup and Scar Extender**, credited to Kazstralities/Astralities/Kaz. It does not bundle KAVT tattoo textures.

The KAVT Nexus page states: "You are allowed to use the assets in this file without permission as long as you credit me." The page also prohibits earning Donation Points when its assets are used. Therefore this release must:

- retain this KAVT credit;
- keep KAVT textures out of the archive; and
- have Nexus Donation Points disabled for the uploaded file/mod if these compatibility definitions are shipped.

Primary permissions source: https://www.nexusmods.com/baldursgate3/mods/16325

This note records the published permission terms used for release preparation; it is not a legal opinion.
